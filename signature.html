OVIA

Signature email

Remplis les champs, clique sur « Copier la signature », puis colle-la dans Outlook. Elle est construite en tableaux avec styles en ligne : c'est le seul format que les messageries affichent correctement, sur ordinateur comme sur mobile.

Aperçu Rendu réel en messagerie

L'aperçu est exactement ce qui sera collé : aucune image, aucune police à télécharger, aucun lien externe. Une signature qui repose sur une image se fait bloquer par la plupart des messageries et n'affiche qu'un cadre vide.

Comment l'installer

Outlook (application Windows)

  1. Clique sur « Copier la signature » ci-dessus.
  2. Dans Outlook : Fichier → Options → Courrier → Signatures…
  3. « Nouveau », donne-lui un nom (par exemple Ovia).
  4. Clique dans la grande zone de texte et colle avec Ctrl + V.
  5. À droite, choisis cette signature pour « Nouveaux messages » et « Réponses/transferts ».
  6. OK. Elle s'ajoutera à chaque email automatiquement.

Outlook sur le web / nouveau Outlook

  1. Roue dentée → Courrier → Composer et répondre.
  2. Colle dans la zone « Signature électronique », puis Enregistrer.

Gmail

  1. Roue dentée → Voir tous les paramètres → onglet Général.
  2. Descends jusqu'à « Signature », crée-en une et colle.
  3. Tout en bas de la page : « Enregistrer les modifications ».

Si le collage arrive sans mise en forme, la messagerie est en mode texte brut : repasse en HTML (ou « Texte enrichi ») avant de coller.
